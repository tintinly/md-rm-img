# Markdown笔记未引用图片清理脚本

## 简介

如果在 Typora 中删除（不以 `Ctrl + Z` 撤回的方式） Markdown 文档的图片后，本地资源文件夹中依然还有被删除的图片。

`md-rm-img.py` 是一个专为强迫症设计的 Python 脚本，用于自动清理 Markdown 笔记目录中未被引用的图片。脚本会递归扫描所有 `.md` 文件，提取文档中实际引用的图片地址，并与对应 `assets` 文件夹中的图片进行对比，将未引用的图片移动到统一的备份目录，同时报告可能无效的图片引用。

## 功能特性

- 递归处理指定目录下的所有 Markdown 文档
- 经过验证的正则表达式，支持 `![alt](url)` 和 `<img src="url">` 两种图片引用语法
- 自动识别 `assets` 文件夹中的本地图片
- 将未引用的图片移动到 `未被引用的图片/{文档名}_assets/` 目录（保留原始结构）
- 输出警告信息，提醒用户检查无效的图片地址（如网络图片、绝对路径、文件不存在等）
- 安全移动，避免直接删除，便于后续恢复或确认

## 环境要求

- Python 3.6 及以上版本
- 操作系统：Windows/Linux/macOS

## 配置说明

在运行脚本前，请根据实际情况修改脚本顶部的配置参数：

| 变量名             | 说明                                                                 | 示例值                                |
| ------------------ | -------------------------------------------------------------------- | ------------------------------------- |
| `ROOT_DIR`         | 存放 Markdown 笔记的根目录（脚本会递归扫描该目录下的所有 `.md` 文件） | `"D:/MyNotes"`              |
| `IGNORED_MD_LIST`  | 忽略处理的 Markdown 文件名列表（不含路径，仅文件名）                  | `["README.md", "TODO.md"]`            |
| `ASSETS_NAME`      | 存放图片的文件夹名称（默认为 `"assets"`）                            | `"images"` 或 `"assets"`（也可扩展为 `{文档名}.assets`）              |

## 使用方法

1. 按上述配置修改脚本中的参数。
2. 打开终端（cmd / PowerShell / bash），进入脚本所在目录。
3. 运行脚本：

```bash
python md-rm-img.py
